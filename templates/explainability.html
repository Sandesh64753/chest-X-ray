🧠 Explainable AI (Grad-CAM Methodology)

Learn how ChestVision AI extracts visual attention heatmaps from deep convolutional feature layers.

What is Grad-CAM?

Gradient-weighted Class Activation Mapping (Grad-CAM) uses the gradients of any target concept (e.g., predicted class 'COVID') flowing into the final convolutional layer of a deep neural network to produce a coarse localization map highlighting the important regions in the image for predicting that concept.

⚙️ Grad-CAM Mathematical Flow

  1. Feature Map Extraction:
    Pass X-ray tensor A through DenseNet121 backbone layer densenet121 to extract spatial feature map Ak.
  2. Gradient Computation:
    Compute gradients of class score yc with respect to feature activation maps Ak.
  3. Global Average Pooling Weights:
    Pool gradients over spatial height u and width v to compute channel importance weights αkc.
  4. Weighted Combination & ReLU:
    Perform linear combination of feature maps weighted by αkc, followed by ReLU activation to extract positive contributions only.

📍 Spatial Activation Centroid Calculation

To convert raw heatmaps into plain spatial descriptions, ChestVision AI locates the spatial centroid of high-activation pixels (activation ≥ 0.6):

  • Grid Partitioning:
    The 224×224 normalized heatmap is divided into a 3×3 grid:
    • Vertical: Upper (y < 0.33), Central (0.33 ≤ y ≤ 0.66), Lower (y > 0.66)
    • Horizontal: Left (x < 0.33), Central (0.33 ≤ x ≤ 0.66), Right (x > 0.66)
  • Output Description Examples:
    • upper-right lung field
    • central lung field
    • diffuse regions across the lung fields
