ℹ️ About ChestVision AI

Production-grade medical AI dashboard ported to FastAPI framework.

Project Overview

ChestVision AI is an explainable deep learning prototype designed for multi-task chest radiograph analysis. It integrates state-of-the-art computer vision architectures to perform automated classification, pixel-level lung field segmentation, and visual model explainability via Grad-CAM.

Training Dataset

Models were trained and evaluated on the public COVID-19 Radiography Database, comprising chest radiograph images categorized into four distinct groups:

  • COVID: Confirmed COVID-19 cases
  • Lung_Opacity: Non-COVID lung opacities
  • Normal: Healthy control chest radiographs
  • Viral Pneumonia: Viral pneumonia chest radiographs

Technology Stack

Python • FastAPI • Uvicorn • Jinja2 HTML Templates • TensorFlow / Keras • OpenCV • NumPy • Pandas • Chart.js
