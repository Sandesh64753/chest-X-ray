📊 Deep Learning Model Architecture

Detailed breakdown of the classification, segmentation, and preprocessing pipelines.

1. Classification Model

  • Backbone: DenseNet121 pretrained on ImageNet
  • Input Shape: 224 × 224 × 3
  • Head Layers:
    • GlobalAveragePooling2D
    • BatchNormalization
    • Dropout (0.4)
    • Dense (256, ReLU, L2 regularized)
    • Dropout (0.3)
    • Dense (4, Softmax)
  • Learned Classes: COVID, Lung_Opacity, Normal, Viral Pneumonia

2. Segmentation Model

  • Architecture: Custom U-Net
  • Input Shape: 224 × 224 × 3
  • Encoder: 4 Convolution Blocks (32 ➔ 64 ➔ 128 ➔ 256 filters)
  • Bottleneck: 512 filters
  • Decoder: 4 Transposed Conv Blocks + Skip Connections
  • Output Layer: Conv2D (1 filter, Sigmoid activation)
  • Mask Threshold: 0.5

⚙️ Model Preprocessing Specifications

Classification Preprocessing (DenseNet121):

  • Image resized to 224 × 224 RGB.
  • Standard densenet.preprocess_input applied (zero-centering per channel with respect to ImageNet dataset).
  • Expand batch dimension: (1, 224, 224, 3).

Segmentation Preprocessing (U-Net):

  • Image resized to 224 × 224 RGB.
  • Cast to float32 and normalized to [0.0, 1.0] range by dividing by 255.0.
  • Binary threshold applied to output logits at 0.5.
